## ✨ Design Rules Used in Every Template
1. **Lead with the answer:** status, decision needed, or key message comes first.
2. **One page where possible:** busy readers skim.
3. **RAG status with a reason:** never a colour without an explanation.
4. **Every action has an owner and a date.**
5. **Plain language:** no jargon the audience would not use themselves.
